◆ 关于游戏

一场关于生存与精准的星海试炼

《星空射击》是一款由 My_Underline 独立开发的俯视角射击游戏。 你将被投放至一片被敌人包围的星域，在有限的资源与不断涌来的威胁之间， 用每一发子弹的落点，决定自己能活多久。

游戏采用 120 FPS 高刷新率渲染，配合平滑的相机震动、 粒子反馈与动态光影，让每一次击杀、每一次弹反都有清晰的触感。

从手枪到火箭筒，从商店补给到小刀弹反， 所有系统都为同一个目标服务——让你打得更爽、活得更久。

◆ 武器库

八种武器，八种节奏

从轻巧的手枪到沉重的火箭筒，每把武器都有独立的伤害、射速与弹夹容量。 找到属于你的那把，然后把它练到极致。

◆ 难度选择

四种难度，四种活法

难度不仅改变敌人强度，也改变了商店物价、玩家生命上限与移动速度。 绝望模式下，物价翻倍——但你也会变得更强。

◆ Mod 支持

把游戏，变成你的形状

一个 zip 包，就能为游戏注入全新的武器、敌人、难度与皮肤。 不需要编译，不需要拆包，拖进去就行。

my_mod / mod.json
{ "id": "neon_arsenal", "name": "霓虹军械库", "version": "1.0.0", "author": "My_Underline" } // 同时可附带： weapons.json // 自定义武器 enemies.json // 自定义敌人 shop_items.json // 商店物品 difficulties.json // 自定义难度 skins.json // 玩家皮肤 gameplay.json // 全局玩法修正
🔫

武器与敌人注入

通过 JSON 定义伤害、射速、弹道颜色甚至彩虹拖尾，自动接入商店与掉落系统。

🎚️

自定义难度

Mod 可以新增独立难度，并拥有专属颜色、生命倍率与物价系数。

🎨

皮肤拓展

为玩家添加新的配色皮肤，自动出现在设置界面中，无需额外代码。

🔄

存档兼容
